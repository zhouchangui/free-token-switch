# TokensBuddy 视觉系统

## 已确认方向

- 方向名称: 路由矩阵（Route Matrix）
- 目标类型: App、Tool、Developer product、Website
- 品牌语言版本:
  - 品牌主名: TokensBuddy
  - 中文辅助名: Token 搭子
  - 主标语: 让闲置 Token 流动起来
  - 能力句: 面向 AI 编码工具的本地 Token 控制台，支持 Provider 切换、可控分享与市场交易。

## 阶段门

- 决策状态: needs-user-feedback
- 用户已确认: 否
- 确认时间:
- 下一允许阶段: 资产生成门
- 允许生成资产: 否

## 视觉原则

- 控制先于流动: 用户先看见当前状态、边界和可停止能力，再感知 Token 正在流动。
- 矩阵只在关键处出现: 路由线、节点、网格用于品牌图、分享流程、市场发布和关键状态，不铺满每个页面。
- 市场是节点，不是中心: 市场能力在视觉上属于受控路径的一端，不能主导整个产品气质。
- 真实 UI 优先: 官网和社媒图应露出真实产品面板、Provider 节点和状态，不用纯抽象 AI 背景。
- 低干扰专业感: App 内保持密集、安静、可扫描，避免霓虹、强发光、渐变堆叠和卡片嵌套。

## 色彩系统

- 主色:
  - Matrix Blue: `#2563EB`
  - 用途: 主行动、当前 Provider、选中态、焦点环、官网主 CTA。
- 辅助色:
  - Route Cyan: `#0891B2`
  - 用途: 受控路径、路由线、共享导入、连接中状态。
  - Health Emerald: `#059669`
  - 用途: 通道健康、可用 Provider、分享运行中、成功。
- 强调色:
  - Ledger Amber: `#D97706`
  - 用途: 市场价格、付款确认、发布待确认、警告。
  - Buddy Coral: `#E11D48`
  - 用途: 少量分享温度、邀请成功、社媒局部点缀；不用于密钥、付款、删除。

  - 信息: `#2563EB`
  - 成功: `#059669`
  - 警告: `#D97706`

  - 中断/停止: `#B91C1C`
- 中性色:
  - Light background: `#F8FAFC`
  - Light surface: `#FFFFFF`
  - Light elevated: `#F1F5F9`
  - Light border: `#D8DEE8`
  - Light text: `#0F172A`
  - Light muted: `#64748B`
  - Dark background: `#0B1120`
  - Dark surface: `#111827`
  - Dark elevated: `#1E293B`

- 文本色:
  - 主文本使用高对比中性文字。
  - 彩色文字仅用于状态、链接、重点数字和短标签。

## 字体系统

- 展示字:
  - 官网首屏使用系统 sans，字重 700-800。
  - 不使用负字距；中文和中英混排 `letter-spacing: 0`。
- 标题:
  - App 内标题 14-18px，保持紧凑。
  - 官网章节标题 28-40px，避免营销式超大标题。
- 正文:
  - 系统字体栈: `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `"Helvetica Neue"`, `Arial`, `sans-serif`。
  - App 正文 13-14px，官网正文 15-17px。
- 注释:
  - 12px 左右，用于风险提示、权限边界、状态解释。
- 界面文字:
  - 动词优先，短句优先。
  - 推荐: “启动分享通道”“停止分享”“测试 Provider”“发布到市场”“复制导入链接”。
  - 避免: “一键暴利”“极速变现”“流动性释放”。
- 等宽字体:
  - 用于 endpoint、Token 片段、路由标签、模型 ID、订单号和命令。

## 形状与布局

- 圆角:
  - App 卡片 / 面板: 8px。
  - 大面板 / 官网截图容器: 10-12px。
  - 徽标 / 通道胶囊: 999px。
  - 高风险确认弹窗: 8px，避免过度柔软。
- 间距:
  - App 紧凑节奏: 4 / 8 / 12 / 16 / 24px。
  - 官网节奏: 24 / 40 / 64 / 96px。
- 密度:
  - Provider、市场、用量、设置页保持高密度。
  - 空状态、首次引导、分享成功页可适度放松。
- 描边:
  - 默认 1px 中性边框。
  - 当前 Provider: Matrix Blue 边框。
  - 分享运行中 / 健康: Health Emerald 边框。
  - 市场待确认 / 价格: Ledger Amber 边框。
- 动效:
  - 路由流动: 低速、低透明度、只在品牌图和关键状态出现。
  - UI 交互: 150-220ms。
  - 高风险操作不使用庆祝动效。
  - 必须支持 `prefers-reduced-motion`。

## 路由矩阵图形语言

- 节点:
  - Provider 节点: 圆角方块或小圆点。
  - 工具节点: 使用 app icon / provider icon。
  - 分享节点: 绿色状态点 + 链路胶囊。
  - 市场节点: 琥珀状态点，仅在市场流程出现。
- 路径:
  - 默认细线 1px。
  - 激活路径 2px 或低透明填充。
  - 路径不得穿越敏感信息或遮挡文字。
- 边界:
  - 本地区域、分享区域、市场区域要有清楚分区。
  - “市场”作为受控出口，不放在画面中心。
- 网格:
  - 仅作为轻量背景纹理或布局辅助。
  - 深色网格透明度建议低于 12%。

## Logo 与 Icon 简报

- 期望隐喻:
  - 3-4 个节点 + 一条受控路径。
  - 本地控制台、Provider 切换、Token packet、分享/市场出口。
  - 可以暗示字母 T / B，但不强求。
- 禁止隐喻:
  - 钱币、K 线、交易所、钱包、保险箱堆叠、火箭、闪电暴富、区块链币面。
  - 通用 AI 球体、星云、渐变花瓣。
  - 强吉祥物或人物头像。
- 必需变体:
  - App icon: macOS / Windows / Linux。
  - favicon: 16 / 32 / 48px。
  - 单色 mark: 菜单栏、文档、深浅色工具栏。
  - 横版 logo: 官网、README、社媒页头。
  - 社交头像: 方形和圆形裁切都可读。

## 官网设计说明

- 首屏:
  - H1 使用 “TokensBuddy” 或 “让闲置 Token 流动起来”。
  - 副标题说明“本地 Token 控制台，支持 Provider 切换、可控分享与市场交易”。
  - 视觉主体: 真实 App 面板 + 路由矩阵叠层。
- 页面节奏:
  - 第一屏: 品牌承诺 + 产品真实信号。
  - 第二屏: 多 AI 编码工具 Provider 控制台。
  - 第三屏: 闲置 Token 如何通过受控路径分享或发布。
  - 第四屏: 安全边界: 可见、可测试、可停止、可回退。
  - 第五屏: 下载 / GitHub / tokensbuddy.com。
- 卡片:
  - 卡片用于功能模块、流程步骤、状态记录。
  - 不使用纯装饰卡片。
  - 不把卡片放进卡片。
- 行动按钮:
  - 主行动: 下载 TokensBuddy。
  - 次行动: 查看 GitHub / 了解分享流程。
- 图像:
  - 优先 SVG / HTML/CSS 产品 mockup 和真实截图。
  - 不使用模糊人物、抽象 AI 球体、纯渐变 hero。
