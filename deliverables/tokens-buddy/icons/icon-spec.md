# TokensBuddy Icon 规范

## 范围

本规范覆盖 app icon、产品功能 icon、技术分类 icon、分享/市场流程 icon。第四阶段确认前不生成任何实际 icon 文件。

## App Icon

- 视觉方向: 流动控制台。
- 核心结构:
  - 中心 Token 节点。
  - 2-4 条受控流动路径。
  - 可保留轻微多色，但整体应更简洁。
- 必需尺寸:
  - 16、20、24、32、48、64、128、256、512、1024px。
- 必需格式:
  - SVG 源文件。
  - PNG 多尺寸导出。
  - macOS ICNS。
  - Windows ICO。

## 功能 Icon

| 类别 | 视觉隐喻 | 建议图标语言 |
| --- | --- | --- |
| Provider 切换 | 分岔、切换、节点 | 线性图标，蓝色激活态 |
| Token 分享 | 受控连接、链接、邀请 | 线性图标，绿色/珊瑚色状态 |
| 市场发布 | 轨道、发布、挂牌 | 线性图标，琥珀色强调 |
| 用量与额度 | 仪表、条形、余额 | 数据图标，中性色为主 |
| 本地代理 | 路由、端口、通道 | 技术线性图标，蓝青色 |
| 安全边界 | 停止、回退、权限 | 不用过重锁头，优先用边界/开关 |

## 风格规则

- 默认使用 1.75-2px 线宽。
- 圆角端点，避免尖锐金融感。
- 16px 下保持单一主体，不堆叠多个复杂元素。
- 彩色 icon 只用于品牌和关键状态；普通功能 icon 优先 currentColor。
- 与现有 Lucide 风格兼容。

## 状态规则

- 默认: 中性文字色。
- Hover: 主蓝色。
- 当前/激活: 主蓝色背景或蓝色描边。
- 分享健康: 翠绿色。
- 市场/价格: 琥珀色。
- 错误/停止: 红色。

## 禁止方向

- 不使用币面、钱包、K 线、火箭、礼物盒表达市场价值。
- 不使用表情化头像表达搭子。
- 不使用过多渐变或多层阴影，避免与工具 UI 冲突。

## 生成前需要确认

- 是否替换现有 app icon。
- 是否需要同时补齐所有平台尺寸。
- 是否需要为 README / 官网生成一套技术分类 icon。
- 是否需要为市场卡片生成专门的 listing icon。
