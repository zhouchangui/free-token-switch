# TokensBuddy Logo 简报

## 目标

Logo 需要表达 TokensBuddy 从 cc-switch 式 Token / Provider 切换出发，进一步支持 Token 分享与交易。它应该像一个“受控流动的开发者工具”，而不是市场交易所、钱包或社交应用。

## 核心隐喻

- Token 节点: 多个来源、多个 Provider、多个额度。
- 切换路径: 从一个工具或 Provider 切到另一个工具或 Provider。
- 受控流动: Token 可以从本地使用流向好友分享或市场发布，但路径清楚、有边界。
- 搭子关系: 可以有轻微连接感，但不做强人物、强吉祥物。

## 推荐方向

- 方向 1: 径向流动标记
  - 从现有多彩径向 app icon 演进。
  - 通过更少的颜色、更清晰的负形和更稳定的中心结构提升识别度。
  - 适合保留产品连续性。
- 方向 2: 节点路径标记
  - 2-4 个 Token 节点通过受控路径连接。
  - 可暗示切换、分享和市场流转。
  - 适合做小尺寸 icon 和官网图形系统。
- 方向 3: 轨道切换标记
  - 使用分岔轨道或切换节点表达从本地到分享/市场。
  - 适合强调“从切换到流通”的产品升级。
  - 风险是太偏交易或物流，需要克制。

## 禁止方向

- 钱币、钱包、K 线、交易所、火箭、收益箭头。
- 过度可爱的角色、动物、头像或表情。
- 复杂渐变图案，导致 16px / 32px 不可识别。
- 完全抽象的 AI 光球或星云，无法表达 Token 切换和流动。

## 必需变体

- App icon:
  - 1024x1024 源文件。
  - macOS 圆角适配。
  - Windows / Linux 启动器适配。
- 小尺寸 icon:
  - 16、20、24、32、48、64px。
  - 小尺寸必须保留核心流动/节点识别。
- 单色版:
  - 用于菜单栏、文档、状态栏、深浅色工具栏。
- 横向组合标:
  - Icon + TokensBuddy。
  - 可加中文辅助名“Token 搭子”的中文传播版。
- 反白版:
  - 用于深色首屏、深色社媒卡片、README 深色徽章。

## 生成前需要确认

- 是否保留当前 app icon 的多彩径向流动基因。
- 是否需要中文组合标“TokensBuddy / Token 搭子”。
- 是否先产出一个方向，还是同时产出 2-3 个 logo 草案方向。
- 输出格式: SVG、PNG、ICO、ICNS 是否都需要。
