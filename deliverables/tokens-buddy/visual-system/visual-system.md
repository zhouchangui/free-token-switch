# TokensBuddy 视觉系统

## 已确认方向

- 方向名称: 流动控制台为主，搭子网络为温度层，Token 流通轨道为市场子语言
- 目标类型: App、Tool、Developer product、Website
- 品牌语言版本:
  - 主标语: 让闲置的 Token 流动起来
  - 能力句: 面向 AI 编码工具的 Token 切换、分享与交易工作台。
  - 核心判断: 切换是基础能力，分享和交易是新增价值，流动是品牌故事。

## 阶段门

- 决策状态: 需要用户反馈
- 用户已确认: 否
- 确认时间:
- 下一允许阶段: 资产生成门
- 允许生成资产: 否

## 视觉原则

- 先可信，再流动: 所有视觉表达先让用户相信“Token 在可控边界内”，再表达分享和交易。
- 工具效率优先: App 内保持密集、可扫描、低干扰，不做营销式大标题和装饰性大卡片。
- 流动有边界: 流线、轨道、节点都要表现“从哪里来、到哪里去、是否可停止”，不能像无边界扩散。
- 温度只在合适位置出现: “搭子”感用于空状态、引导、分享成功、好友通道，不用于付款、密钥、权限确认等高风险场景。
- 市场子语言受控: 交易、价格、结算使用独立状态和颜色，不侵占全局品牌。

## 色彩系统

- 主色:
  - TokensBuddy Blue: `#0A84FF`
  - 用途: 主按钮、当前 Provider、选中态、关键导航、官网主行动按钮。
- 辅助色:
  - Flow Cyan: `#22D3EE`
  - 用途: Token 流线、路由高亮、连接状态、官网流动图形。
  - Flow Emerald: `#10B981`
  - 用途: 通道健康、分享已启用、可用资源、成功状态。
- 强调色:
  - Buddy Coral: `#F97366`
  - 用途: 好友分享、人情味提示、社媒卡片局部点缀。
  - Rail Amber: `#F59E0B`
  - 用途: 价格、付款、市场警告、需要确认的交易步骤。
- 语义色:
  - 成功: `#10B981`
  - 警告: `#F59E0B`
  - 错误: `#EF4444`
  - 信息: `#0A84FF`
- 中性色:
  - Light surface: `#FFFFFF` / `#FAFAFA` / `#F4F4F5`
  - Light border: `#E4E4E7`
  - Light text: `#18181B` / `#71717A`
  - Dark surface: `#1C1C1E` / `#2C2C2E` / `#3A3A3C`
  - Dark border: `#3F3F46`
  - Dark text: `#FAFAFA` / `#A1A1AA`
- 背景色:
  - App 背景保持当前浅深色变量体系，避免大面积彩色背景。

- 文本色:
  - 主文本优先高对比中性文字。
  - 彩色文字只用于状态、链接和重点数字，不用于大段正文。

## 字体系统

- 展示字:
  - 官网首屏标题使用系统无衬线粗体，克制使用大字号。
  - 中文标题避免过度口号化，优先清楚表达产品价值。
- 标题:
  - App 内标题保持 14-18px 区间，信息面板标题紧凑。
  - 官网章节标题可使用 28-40px，但不使用夸张字距。
- 正文:
  - 使用系统字体栈: `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `Arial`, `sans-serif`。
  - 官网正文保持 15-17px，App 正文保持当前 13-14px。
- 注释:
  - 使用 12px 左右灰色文字，承载风险提示、权限边界、状态解释。
- 界面文字:
  - 保持短句和动词优先，例如“启动分享通道”“停止分享”“发布到市场”“复制导入链接”。
  - 等宽字体只用于 endpoint、Token 片段、交易号、路由标签、命令。

## 形状与布局

- 圆角:
  - App 主容器和卡片: 8-12px。
  - 状态徽标、胶囊按钮、分享链接: 999px 胶囊。
  - 高风险确认弹窗不要过圆，保持严肃。
- 间距:
  - App 密集区使用 8/12/16/24px 节奏。
  - 官网使用 24/48/72px 节奏，但避免过度留白导致产品感变弱。
- 密度:
  - Provider、市场、交易、用量区域保持高密度。
  - 官网首屏可更开阔，但必须给出真实产品信号。
- 描边:
  - 默认 1px 中性边框。
  - 激活 Provider / 当前通道使用蓝色或绿色边框。
  - 市场/付款步骤使用琥珀边框，但不能大面积变橙。
- 动效:
  - 流动路径可用低速、低透明度线性动效。
  - 状态切换使用 150-250ms。
  - 遵守 reduced motion；高风险确认不使用庆祝动效。

## Logo 与 Icon 简报

- 期望隐喻:
  - Token 节点、切换路径、受控流动、从本地到分享/市场的边界。
  - 可以从现有多彩径向 icon 演进，保留“流动”和“多源”的直觉。
- 禁止隐喻:
  - 钱币、K 线、交易所、火箭、闪电暴富、保险箱锁头过度堆叠、强吉祥物。
  - 不能像加密货币项目或支付钱包。
- 必需变体:
  - App icon: macOS / Windows / Linux 桌面启动器。
  - 小尺寸 icon: 16/20/24/32px 仍可识别。
  - 单色 icon: 菜单栏、深浅色工具栏、文档页。
  - 横向组合标: 官网、README、社媒页头。

## 官网设计说明

- 首屏:
  - 主标题建议使用“让闲置的 Token 流动起来”。
  - 副标题补足“切换、分享、交易”三件事。
  - 背景应展示真实产品工作台或抽象但具体的 Provider 节点流动图。
- 页面节奏:
  - 第一屏: 品牌承诺 + 产品真实信号。
  - 第二屏: 从 cc-switch 式切换到 TokensBuddy 流动能力。
  - 第三屏: 三个场景，自用切换、好友分享、市场交易。
  - 第四屏: 安全边界，可停止、可回退、可见状态。
  - 第五屏: 下载 / GitHub / tokensbuddy.com 入口。
- 卡片:
  - 卡片只用于功能模块、流程步骤、资源状态，不做纯装饰卡片。
  - 卡片内标题短，信息密度高，和 App 气质一致。
- 行动按钮:
  - 主行动: 下载 TokensBuddy / 查看 GitHub。
  - 次行动: 了解 Token 分享 / 查看市场流程。
- 图像:
  - 优先产品截图、界面局部、流程图、路由图。
  - 不使用模糊人物、抽象 AI 球体、纯渐变英雄图。
